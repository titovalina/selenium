# Selenium Final Project

Учебный проект по автоматизации тестирования интернет-магазина
с использованием Python, Selenium WebDriver и pytest.

## Технологии

- Python
- Selenium WebDriver
- pytest
- Page Object Model

## Структура проекта

- `pages/` — классы страниц и локаторы.
- `test_main_page.py` — тесты главной страницы.
- `test_product_page.py` — тесты страницы товара и корзины.
- `conftest.py` — фикстура браузера.
- `pytest.ini` — настройки pytest.
- `requirements.txt` — зависимости.

## Установка

```bash
python -m pip install -r requirements.txt
